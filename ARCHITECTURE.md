# NexusAI Platform Architecture

NexusAI transforms multi-format enterprise business data into decision-grade executive insights using a strictly grounded, deterministic analytical pipeline.

---

## 2. Core Subsystems

### A. Data Ingestion Service (`server/fileIngestion.ts`)
- Accepts CSV, Excel (`.xlsx`, `.xls`), JSON, and raw SQL dumps.
- Cleans and normalizes column headers into standard snake_case identifiers.
- Sanitizes values, normalizes dates to ISO-8601 strings, and converts numeric strings.

### B. Mathematical Profiling Engine (`server/dataProfiler.ts`)
- Computes distribution parameters: min, max, mean, median, standard deviation, IQR, and 1.5x IQR outliers.
- Detects exact row duplicates and null cell frequencies.
- Evaluates data quality penalties to output a standardized 0–100 Data Health Score.

### C. Dynamic KPI & Problem Detection Engine (`server/kpiEngine.ts`)
- Discovers metric candidates (revenue, profit, cost, units, price) without hardcoding column names.
- Computes period-over-period changes, growth trajectories, and volume-weighted margins.
- Emits business problems with severity, impact scores, and exact evidence records.

### D. AST-Validated SQL Security Layer (`server/sqlSecurityService.ts`)
- Restricts execution exclusively to `SELECT` and `WITH` (Common Table Expression) queries.
- Blocks data modification and administrative operations (`INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`, `GRANT`).
- Enforces execution limits: maximum row caps (500 rows) and query timeout gates (8000ms).

### E. Evidence-Grounded AI Analysis (`server/geminiService.ts`)
- AI responses strictly ingest computed KPIs, detected problems, and SQL execution results.
- Never fabricates trends, cohorts, or margins.
- Generates strategic recommendations complete with source column lineage and suggested verification SQL.

## 3. Data Flow Pipeline

1. **Upload**: User posts a dataset through the UI or REST endpoint.
2. **Ingest**: File parser normalizes rows and extracts column headers.
3. **Profile**: Profiling engine generates statistical distribution and data health scoring.
4. **Persist**: Database layer commits the dataset and column metadata.
5. **Analyze**: KPI engine dynamically calculates business metrics and flags operational anomalies.
6. **Query**: SQL security layer processes queries from analysts or generated by the AI agent.
7. **Explain**: Gemini model synthesizes executive summaries and evidence-backed recommendations based solely on actual dataset results.
